# 리허설 기록 (2026-11-18 ~ 11-21)

헌장과 세 스킬 초안을, 작업 맥락을 받지 않은 별도 에이전트 넷에게 시험했다. 에이전트는 지정한 파일만 읽었다(결함 대장과 원래 검토문은 금지).

| # | 시험 | 정답지 | 결과 |
|---|---|---|---|
| R1 | 계획 스킬: 『충격과 대응』 요청(검토 전의 의도만) | 목차 검토의 여섯 지적 | 여섯 모두 스스로 짚음. 사건 단위 대신 장면+입장 기준(①②), 1910년 뒤 전제 붕괴(③, 강), '충격–대응' 틀과 '친일·애국계몽' 같은 평가어(④), 서학·기독교 흐름 누락(⑤, 강), 흐름별 장 공백(⑥), 여성 포함 기준(⑤). 다만 헌장이 이 책의 교훈을 담고 있어 순수한 독립 시험은 아니다 |
| R2 | 출간 스킬의 독립 검수: 『계몽의 갈래』 7개 장 표본 | 앞선 검수가 이 표본에서 찾은 14건 | 11건 재발견(79%). 놓친 것: 요약↔본문 시점 충돌 1, 확신도 낮던 직함·나이 2. 새 지적 46건(강 20여 건). 웹 열람 한도에 걸림 → 검수를 장 7~10개씩 나누는 규칙으로 |
| R3 | 계획 스킬: 『회의주의의 역사』(새 주제) | 없음 | 구조가 다른 세 안(정식화 단위 52장 / 논변 단위 물음별 24장 / 논쟁 장면 40장). 60장 사건형으로 쏠리지 않음. 헌장의 역사서 편향 지적 15건 |
| R4 | 계획 스킬: 『통계적 추론의 쟁점』(비역사 분야) | 없음 | 쟁점 지도 / 논쟁 연대기 / 사례 단위의 세 안. 엔진 적합성 점검과 서재 소속 문제, 수식 검증 규칙의 부재를 지적 |

네 시험의 피드백으로 헌장과 스킬을 고쳤다(LIBRARY §11 개정 기록).
