## 파일 구조
- `data.mjs` META·REGIONS·AXES·ENGINES·KINDS·PARTS·GROUPS·THREADS·THREAD_EV (책의 뼈대)
- `events.mjs` 60장 목록: id, p(부), t, y, yr, r(무대), pl[이름,경도,위도], w(1 핵심/2 주요), g(세 힘), nx(이어지는 장), kd('th' 사상 장), q(물음), s(핵심 요약)
- `links.mjs` WHY: `'원인>결과':'이유 한 문장'` — nx마다 하나씩(빌드가 빠진 것을 잡아낸다)
- `body_pNa.mjs`, `body_pNb.mjs` 부별 본문(export const BNA/BNB). 키: 안내[], 배경[], 원인[], 주체[], 전개[], 영향[], 갈림[], 오해[], 말[[낱말,풀이]], 작품[[제목,'연도 · 사람',설명]]. 다른 장은 `[[n05]]`처럼 적으면 링크가 된다. 사상 장(kd:'th')은 절 이름이 뿌리·물음·사람과 글·흐름으로 바뀐다. 주요 장은 ‘안내’를 생략해도 된다.
- `partN.mjs` PN{f:{top,bot,out,meet}, bg:{무대 id:문단}, bgx:['## 소제목','문단',...], sum:[문단×3]}, GROUP_CHN{집단 id:[[장,겹,설명]]}, AXCHN{장:[[겹,설명]]}
- `people.mjs` FACTS(진영)·PEOPLE(1부 인물)·PDENY / `people_pN.mjs` PEOPLEN·ATN(기존 인물의 새 장 행적)·RELN(관계)·PDENYN. 인물: P(id,n,al[별칭],hz(원어),life[생,몰],f(진영),role,d,at{장:행적}).
- `terms.mjs` TCATS·TERMS([표제,풀이,분야]) / `books.mjs` BOOKS({id,lang,t,a,o,role,warn})·BK{장:[[책 id,근거 부분]]}
- 이후 마무리 단계용: `concl.mjs`(맺음), `lineage.mjs`+`lnb1–3.mjs`(요소별 변천), `make_guide.py`(안내서), `thumb_make.py`(썸네일) — 앞선 책(소련사) 것을 본떠 만든다.

## 한 단계(한 부 10장) 작업 순서
1. 사실 메모를 먼저 정리한다(날짜·숫자·인용은 확실한 것만. 불확실하면 쓰지 않거나 ‘전해진다’로).
2. `body_pNa.mjs`(앞 5–6장), `body_pNb.mjs`(뒤 4–5장)를 쓴다.
3. `people_pN.mjs`, `partN.mjs`를 쓰고, 용어·서가는 `python3 app.py terms|books|bk <파일>`로 덧붙인다(형식은 app.py 머리 참조).
4. `node build.mjs`가 장별 길이를 출력한다. 모자라면 `sp/x.json`에 `[{"c":"n05","s":"전개","t":"문단","at":위치}]`를 쓰고 `node addp.mjs sp/x.json`. 말/작품 항목은 t에 배열을 준다.
5. `node ppcheck.mjs <장>`으로 본문에서 잡힌 인물을 확인한다. 같은 이름이 다른 사람·지명에 잡히면 PDENY `{'이름':[앞 정규식,뒤 정규식]}`로 막는다.
6. 빌드 → font.py → t1.py(390·1280 오류 없음) → 화면 몇 장을 찍어 확인 → `dist/index.html`을 outputs로 보낸다. PLAN.md에 진행을 적는다.
