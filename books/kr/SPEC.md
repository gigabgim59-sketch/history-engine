# 충격과 대응 — 확정 사양 (질답, 2026-11-16)
- 물음: 스스로 문명이라 자부하던 이들이 낯선 문명을 마주쳤을 때의 행동과 발언. 한국사 자체가 목적이 아니다.
- 교훈을 찾지 않는다. 교훈을 노려 구성하지 않는다. 오로지 그들의 상황과 행동·발언만 서술한다. (부 끝·맺음에도 '교훈' 정리 금지)
- 범위: 1845(『해국도지』 무렵)–1945. 1910년 뒤에는 물음이 '무너진 확신을 다시 세우는 일'로 바뀐다는 것을 머리말에 밝힌다.
- 흐름: 위정척사, 개화(온건·급진·동도서기), 동학, 애국계몽, 친일 협력, 1910년 이후 민족주의 독립운동·사회주의/아나키즘·문화운동/자치론·전향과 협력 — 전부.
- 배치: 사건별 여러 목소리(한 장 안에서 여러 흐름이 각자의 눈으로).
- 문체: 3인칭, 그들 인식 그대로, 원문(상소·논설·격문)을 현대어로 옮긴 인용.
- 바깥 시각: 장 끝 짧은 상자(오늘 연구의 사실 확인)만.
- 흐름 풀이 장(◆) 11개, 저작 시점에 연대순.
- 외부 세력: 지식인들의 눈에서만.
- 등뼈: 보다·지키다·배우다·서다 (서술의 축으로만, 평가 아님).
- 장 기준: 둘 이상의 흐름이 같은 마주침 앞에서 기록을 남겨 갈라진 장면만 장이 된다. 결과 60장 7부, ◆13.
- 용어: 장 제목은 중립(1905년 조약, 1910년 병합), 본문은 흐름마다 당대 이름.
- 제목 '충격과 대응'은 유지하되 머리말에서 페어뱅크 틀과 코헨 비판을 알고 쓴다고 밝힌다.
- 기독교(병인박해, 성산명경), 대종교 포함. 여성은 '문명을 직접 말한 기록이 있을 때'만(여권통문, 윤희순, 나혜석).
- 문헌: 원전 + 한국어 연구서 + 영어 연구서.
- 제목: 충격과 대응.
