# 『공화국의 탄생』 — 계몽에서 제3공화정까지, 유럽이 왕을 없앤 길 (1640–1875)
- 60장·6부(8·14·11·6·13·8), 약 20만 자. 핵심 24(≥4,600) · 주요 34(≥2,300) · 보조 2(≥1,350)
- 사상 2 : 사건 8. 프랑스 절반·유럽 절반. 끝: 1875년 헌법.
- 설명 틀: 구체화의 다섯 고리(생각·결사·위기·제도·전파와 반동) — events.g, 장 머리에 표시. 부 머리 f에 다섯 고리+meet.
- 다섯 겹: 주권(sov)·시민권(cit)·헌정 구조(con)·자유와 권리(lib)·민족과 교회(nat)
- 집단: 도시 민중(pop)·노동자(wor)·농민(pea)·부르주아(bou)
- 무대: 파리(par)·프랑스 지방(fra)·대서양과 북서 유럽(nw)·남유럽(sud)·중부·동유럽(ce). 아메리카 사건은 지도 왼쪽 끝 ‘대서양 건너’에 표시.
- 표기: 원어 발음·국립국어원 외래어 표기법, 관용 우선(나폴레옹, 빈). 인물 hz에 원어.
- 빌드: node build.mjs → python3 font.py dist/index.html → python3 t1.py <폴더>. 인물 점검: node ppcheck.mjs r0
- 본문 파일: body_pN[a-c].mjs (BN, BNA…), 부 머리 partN.mjs (PN, GROUP_CHN, AXCHN), 인물 people.mjs + people_pN.mjs (PEOPLEN, ATN, RELN, PDENYN)
- 보강: node addp.mjs sp/x.json ({c,s,t,at?} 또는 {c,s,after,add})
- 서가: 번역본은 확인된 것만 출판사·옮긴이 표기, 고전 원전은 ‘여러 번역본’.
